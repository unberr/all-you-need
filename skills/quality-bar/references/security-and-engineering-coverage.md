# Coverage of the security and engineering requirement lists

Lists: **A** the 30 security requirements; **B1** the 13 secure-coding, secrets, supply-chain and AI-guardrail items; **B2** the 22 principles and standards (core principles, syntax and quality, cybersecurity, architecture, workflow); **C** the 30 secure-design requirements; **D** the 55 engineering requirements; **E** the 178 full-stack requirements.

Status meanings: **Enforced** = a hook checks it mechanically (patterns only; a hook is never a complete scanner). The stop gate and the guards block; the lint and CVE hooks only report findings to the model and never block, so for them Enforced means detected, not guaranteed. **Guided** = a skill or rule instructs it. **Partial** = some enforced or guided, the rest outside the plugin. **Outside** = not controllable from a plugin.

`tests/test_coverage.py` fails if an item of any list is missing or duplicated, or if a path named here does not exist.
